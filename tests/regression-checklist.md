# Checklist de regresión — MARK I

Antes de considerar estable un avance comprobar:

- Navegación principal y espacios aprobados.
- Menú de usuario: abre, muestra opciones, alterna y cierra al hacer clic fuera.
- Mensajes y notificaciones no interfieren con otros desplegables.
- Ayudas contextuales contienen información específica de cada herramienta.
- Workspace permite acceder a PESTEL, DOFA y Objetivos/Indicadores.
- PESTEL conserva seis dimensiones agrupadas.
- Guardar, Exportar y PDF/Imprimir se mantienen en herramientas activas.
- Persistencia local funciona cuando aplique.
- Trazabilidad evidencia → análisis → decisión → objetivo → indicador se conserva.
- Recuperar, generar y aceptar permanecen diferenciados.
- No se declara una función terminada únicamente porque el JavaScript tenga sintaxis válida.
