# e-Plaza MARK I

Repositorio oficial del desarrollo acumulativo de e-Plaza MARK I.

## Regla principal

`main` representa el último estado estable y verificable de MARK I.

## Estructura

- `docs/`: Plan Maestro, roadmap, decisiones UX y registro de cambios.
- `prototype/`: prototipo funcional vigente.
- `archive/`: hitos históricos conservados.
- `tests/`: controles de regresión y validación funcional.

## Principio JARVIS

Cada avance debe conservar las funcionalidades aprobadas, comprobar regresiones y distinguir entre conocimiento recuperado, propuestas generadas por IA y decisiones aceptadas por personas.
