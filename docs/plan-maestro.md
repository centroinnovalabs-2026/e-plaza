# Plan Maestro — e-Plaza MARK I

Documento persistente para conservar arquitectura, decisiones aprobadas e invariantes del producto entre ejecuciones de JARVIS.

## Regla acumulativa

Cada avance conserva lo aprobado y funcional salvo decisión explícita de sustitución. Antes de integrar un avance debe comprobarse que no existan regresiones.

## Arquitectura principal

Plaza · Explorar · Proyecto Vivo · Workspace · Biblioteca / E-data · Continuidad · Organización · Perfil.

Conexiones funciona como capa social para Mensajes, Foros y Grupos.

## Separación funcional

- Campus Inteligente / Mis ejercicios: práctica académica personal.
- Workspace: análisis contextual del Proyecto Vivo.
- Biblioteca / E-data: infraestructura de conocimiento.
- Investigar: proceso para resolver preguntas.
- Conexiones: interacción académica y profesional.

## Autoría

Recuperar ≠ generar ≠ aceptar. Una propuesta de IA no se convierte automáticamente en decisión humana ni modifica un Proyecto Vivo sin revisión explícita.
