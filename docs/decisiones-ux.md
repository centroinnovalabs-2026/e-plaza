# Decisiones UX — e-Plaza MARK I

Registro persistente de decisiones aprobadas.

- Hero: “Aprender es solo el comienzo.”
- Subtexto: “Investiga, crea, colabora y continúa haciendo crecer el conocimiento.”
- PESTEL: una ficha fija por dimensión con múltiples factores internos.
- Herramientas: Guardar, Exportar y PDF/Imprimir; impresión limitada al resultado de la herramienta.
- Ayuda contextual reutilizable: qué es, para qué sirve, cómo utilizarla y ejemplo/recomendación cuando corresponda.
- Usuario visible en topbar: Carlos · Estudiante / CM.
- Menú de usuario, mensajes y notificaciones deben funcionar como desplegables y cerrar al hacer clic fuera.
